# 小米龙虾miclaw电脑端内测初体验：能控电脑、跨端联动

> 原文链接：[https://www.laoshoucun.com/miclawzn/2323](https://www.laoshoucun.com/miclawzn/2323)

<p>小米的“人车家”多端生态布局又有新动作！其人工智能产品“龙虾”的电脑端（miclaw）首个内测版本现已曝光，具备控制电脑、插件查询、网页生成等能力，未来还将打通多端，为小米生态带来更多可能。</p>
<p><strong>安装便捷，普通台式机也能装</strong></p>
<p>miclaw电脑端的安装过程十分简单。只需双击安装包，选择安装路径（如：D盘），几步操作后即可完成安装，整个过程快捷流畅。而且，它并非仅限小米笔记本，普通台式机也能安装使用。</p>
<p>功能初体验：控制、查询、生成样样行</p>
<p><strong>控制电脑：自动整理桌面</strong></p>
<p>miclaw的首个演示功能是整理桌面。它能自动识别桌面符合条件的文件，新建“工作归档”文件夹，并将这些文件移动到该文件夹中，实现桌面文件的自动整理，展现出对电脑的控制能力。</p>
<p>插件查询：智能获取信息</p>
<p>在查询天气功能中，miclaw调用相关插件，综合信息后不仅能给出天气情况，还能判断是否需要带伞，为用户提供实用建议，体现了其通过插件综合查询并解决问题的能力。</p>
<p>网页生成：快速创建交互页面</p>
<p>miclaw还具备网页生成能力。仅需简单指令，它就能快速创建带有跳动爱心的HTML页面，展现出在代码和网页端生成方面的潜力。</p>
<p>未来可期：跨端联动，小米生态或迎完全体</p>
<p>目前版本中，跨端执行功能尚未实测，但这一功能值得期待。结合小米庞大的“人车家”生态，未来miclaw有望实现米家设备联动、车辆控制等多端互联操作。再加上其具备的上下文记忆功能，如同为小米生态装上了“会思考的大脑”，小米生态的完全体形态或许即将到来。</p>
