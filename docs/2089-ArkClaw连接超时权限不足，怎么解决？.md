# ArkClaw 连接超时/权限不足，怎么解决？

> 原文链接：[https://www.laoshoucun.com/arkclawzn/2089](https://www.laoshoucun.com/arkclawzn/2089)

<p>我们在使用ArkClaw 时候，连接超时和权限不足，是 ArkClaw 最常见的报错。</p>
<p><strong>先说连接超时。</strong>首先看网络：能不能正常访问外部环境，有没有防火墙拦截 ArkClaw 的请求。WiFi 不稳的话切换移动数据试试。</p>

<p>其次，看服务器状态，官方状态页能看到是否出现全局故障。如果是服务器挂了，只能等恢复。如果是本地环境，重启设备、清缓存、重新登录，常常能直接解决。</p>
<p>权限不足则分两种情况。普通成员无法使用某些高级功能，比如删除数据、管理成员。这时候联系管理员提升权限，或者走“权限申请”流程。</p>
<p>如果是文件/任务权限，检查是否被创建者设置了可见范围。外部成员不能访问团队内任务是正常现象，申请即可。如果仍无法解决，记录报错截图和日志，联系右侧我们客服。</p>
