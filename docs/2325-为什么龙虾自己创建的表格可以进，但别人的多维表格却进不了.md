# 为什么龙虾自己创建的表格可以进，但别人的多维表格却进不了

> 原文链接：[https://www.laoshoucun.com/arkclawzn/2325](https://www.laoshoucun.com/arkclawzn/2325)

<div data-lark-html-role="root">为什么<a href="https://www.laoshoucun.com/">龙虾</a>自己创建的表格可以进，但别人的多维表格却进不了，我都给他开了权限了，别人可以打开，龙虾却一直提示进不了？</div>
<div data-lark-html-role="root"></div>
<div data-lark-html-role="root">
<div data-lark-html-role="root">
<div class="rich-text-paragraph" data-eleid="ad426ee6-640b-47b4-a5ac-445c1d572902-0"><span class="text-only" data-eleid="ad426ee6-640b-47b4-a5ac-445c1d572902-0-0">这个问题大概率是飞书应用权限配置或生效问题哦，按照下面步骤依次排查就行： </span><span class="text-only" data-eleid="ad426ee6-640b-47b4-a5ac-445c1d572902-0-1">✅ 第一步：先检查<a href="/arkclaw/">飞书</a>开放平台的应用权限 </span><span class="text-only" data-eleid="ad426ee6-640b-47b4-a5ac-445c1d572902-0-2">登录飞书开发者平台进入你的机器人应用，到「开发配置 &gt; 权限管理」里确认已经添加了「查看多维表格」「编辑多维表格」「管理多维表格」这几个核心权限，权限的数据范围要保持「与应用的可用范围一致」哦。 </span></div>
<div class="rich-text-paragraph" data-eleid="ad426ee6-640b-47b4-a5ac-445c1d572902-0"><span class="text-only" data-eleid="ad426ee6-640b-47b4-a5ac-445c1d572902-0-3">✅ 第二步：确认权限已经发布生效 </span><span class="text-only" data-eleid="ad426ee6-640b-47b4-a5ac-445c1d572902-0-4">改完权限一定要点顶部「创建版本」填好信息发布，新权限要发布之后才会生效，很多小伙伴都忘了这步！</span></div>
<div class="rich-text-paragraph" data-eleid="ad426ee6-640b-47b4-a5ac-445c1d572902-0"><span class="text-only" data-eleid="ad426ee6-640b-47b4-a5ac-445c1d572902-0-5">✅ 第三步：确认多维表格的协作者配置 </span><span class="text-only" data-eleid="ad426ee6-640b-47b4-a5ac-445c1d572902-0-6">如果是别人分享的表格，要确认：</span></div>
<ol class="richTextDocs-orderList richTextDocs-orderList-marker1 richTextDocs-orderList-number" start="1" data-eleid="ad426ee6-640b-47b4-a5ac-445c1d572902-1">
<li class="richTextDocs-listItem" data-eleid="ad426ee6-640b-47b4-a5ac-445c1d572902-1-0" data-index="1.">
<div class="richTextDocs-listItem__text"><span class="text-only" data-eleid="ad426ee6-640b-47b4-a5ac-445c1d572902-1-0-0">要么直接把机器人加到表格的协作者列表里，给对应查看/编辑权限</span></div>
</li>
<li class="richTextDocs-listItem" data-eleid="ad426ee6-640b-47b4-a5ac-445c1d572902-1-1" data-index="2.">
<div class="richTextDocs-listItem__text"><span class="text-only" data-eleid="ad426ee6-640b-47b4-a5ac-445c1d572902-1-1-0">如果给的是父文件夹权限，要确认文件夹的权限继承已经开启，能覆盖到这个多维表格</span></div>
</li>
<li class="richTextDocs-listItem" data-eleid="ad426ee6-640b-47b4-a5ac-445c1d572902-1-2" data-index="3.">
<div class="richTextDocs-listItem__text"><span class="text-only" data-eleid="ad426ee6-640b-47b4-a5ac-445c1d572902-1-2-0">表格的可见范围如果是「仅部分人可见」，要把机器人或者机器人所属的用户组加进去</span></div>
</li>
</ol>
<div class="rich-text-paragraph" data-eleid="ad426ee6-640b-47b4-a5ac-445c1d572902-2"><span class="text-only" data-eleid="ad426ee6-640b-47b4-a5ac-445c1d572902-2-0">✅ 临时规避方案：直接把机器人拉到对应多维表格的协作者里，权限开对马上就能用~</span> <span class="text-only ecff566f" data-eleid="ad426ee6-640b-47b4-a5ac-445c1d572902-2-2">要是上面都排查完还是不行，可以再给我发下具体的报错截图我帮你进一步看哦😉</span></div>
