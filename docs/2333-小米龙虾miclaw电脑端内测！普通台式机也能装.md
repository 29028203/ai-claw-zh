# 小米龙虾 miclaw 电脑端内测！普通台式机也能装

> 原文链接：[https://www.laoshoucun.com/miclawzn/2333](https://www.laoshoucun.com/miclawzn/2333)

<p>近日小米龙虾 miclaw 电脑端首个内测版本正式开启体验，这款备受关注的小米桌面级 AI 智能体迎来电脑端落地，打破专属设备限制，普通台式机也可顺利安装使用，不需一定是小米笔记本机型。</p>
<p>作为全新 PC 端 AI 工具，小米龙虾 miclaw 内测版亮点十足，不仅内置多款预设实用技能，自由度拉满。用户既可以手动自主添加专属技能，也能直接从 Github 平台导入现成技能模板，门槛低、可玩性极强。</p>
<p>更值得关注的是，该版本具备电脑操控能力，依托小米大模型能力实现桌面端智能操控，颠覆传统 AI 工具的使用形态。<br />
后续小米龙虾还将深度联动小米智能家居生态，实现跨设备、跨场景智能协同。目前不少网友也纷纷热议，期待后续能解锁更多智能家居联动玩法，全屋自动化场景、语音联动办公、家居设备一键调度等功能都成为大家期待的方向。</p>
