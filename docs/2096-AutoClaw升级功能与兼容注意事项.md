# AutoClaw升级功能与兼容注意事项

> 原文链接：[https://www.laoshoucun.com/autoclawzl/2096](https://www.laoshoucun.com/autoclawzl/2096)

<p>AutoClaw 新版主要加了三块内容：可视化流程编辑、更灵活的任务调度、数据报表。<br />
<img loading="lazy" decoding="async" class="alignnone wp-image-2097 size-medium" src="https://cdn.laoshoucun.com/web/2026/03/30eb626673014af0421b8e085780a599-300x231.jpeg" alt="" width="300" height="231" srcset="https://cdn.laoshoucun.com/web/2026/03/30eb626673014af0421b8e085780a599-300x231.jpeg 300w, https://cdn.laoshoucun.com/web/2026/03/30eb626673014af0421b8e085780a599.jpeg 650w" sizes="auto, (max-width: 300px) 85vw, 300px" /><br />
可视化流程是最大亮点，不用写代码，通过拖拽模块就能组成自动化流程，新手也能上手。任务调度支持更复杂的周期配置，比如按周、按月，或者触发事件后执行。报表模块则能自动生成脚本运行情况，方便查看效率和问题。</p>
<p>升级前一定要备份脚本，虽然官方兼容大部分旧脚本，但个别依赖旧版 API 的可能要调整。建议先在测试环境验证一下再上线。</p>
<p>系统版本也要注意，最低版本要求比之前高，不够会安装失败。升级流程很简单，后台点检查更新即可。</p>
