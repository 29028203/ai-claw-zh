# ArkClaw效率优化：多端同步与快捷操作

> 原文链接：[https://www.laoshoucun.com/arkclawzn/2086](https://www.laoshoucun.com/arkclawzn/2086)

<p>ArkClaw 真正强的地方是多端同步。登录同一账号，PC、手机、平板的数据会实时同步。你在电脑上建的任务，手机马上能收到提醒；外出也能随时查看和处理。<br />

同步前要保证各端版本一致，不然可能出现同步延迟。如果不同步，先刷新同步状态，检查网络是否稳定。支持离线编辑，断网修改的内容联网后会自动合并，不会丢数据。</p>
<p>快捷操作也很实用。PC 端用快捷键创建任务、切换模块，比点菜单快很多。手机端支持滑动操作，左滑删除、右滑标记完成，基本不用点进详情页。</p>
<p>另外，可以自定义快捷菜单，把高频功能放在首页，比如批量导入、数据导出，一触即达。多端配合，实际效率能提升一大截。</p>
