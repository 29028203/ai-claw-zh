# RedClaw移动端闪退/收不到消息，怎么解决？

> 原文链接：[https://www.laoshoucun.com/redclawzl/2103](https://www.laoshoucun.com/redclawzl/2103)

<p>RedClaw移动端闪退常见原因：系统版本过低、缓存过多、安装包损坏、内存不足。</p>
<p>先检查手机系统版本，低于最低要求会频繁闪退。清除应用缓存后重启，如果还不行就卸载重装。同时别同时开太多应用，留出内存稳定运行。</p>
<p><strong>RedClaw收不到消息怎么解决？</strong></p>
<p>第一检查通知权限，是否关闭 RedClaw 推送。第二看网络，切换 Wi‑Fi 和数据试试。<br />
登录过期也会导致消息中断，重新登录就行。个别联系人收不到要检查是否被设为免打扰。</p>
