# 解决 Auto 澳龙龙虾「没有飞书权限」报错的 2 个核心方法

> 原文链接：[https://www.laoshoucun.com/autoclawzl/2221](https://www.laoshoucun.com/autoclawzl/2221)

<p>在使用 Auto <a href="/autoclaw/">澳龙龙虾</a>时，不少用户会遇到 AI 提示「没有飞书权限」的问题，其实绝大多数情况都可以通过以下两个常见原因排查解决，操作简单高效：</p>
<p><strong>一、最常见原因 1：权限开通后未发布新版本</strong><br />
很多用户在<a href="/arkclaw/">飞书</a>开放平台完成权限申请后，没有创建新版本并发布，会导致权限配置无法生效，AI 就会报权限错误。<br />
✅ 解决方法：<br />
直接进入飞书开放平台，找到对应的应用，创建新版本并完成发布，让权限配置正式生效，即可解决该问题。</p>
<p><strong>二、最常见原因 2：用户 OAuth 授权未完成</strong><br />
如果应用的 OAuth 授权流程没有走完，用户的个人账号就无法正常获取飞书权限，同样会触发报错。<br />
✅ 解决方法：<br />
在飞书对话中，直接发送指令 /feishu auth，按照提示完成 OAuth 授权流程，授权完成后即可正常使用。</p>
<p><strong>补充说明</strong><br />
这两个是该报错的最高发原因，优先按顺序排查，90% 以上的权限问题都能快速解决。如果完成以上操作后仍有问题，可以再检查飞书应用的权限配置是否完整、账号是否有对应功能的使用权限。</p>
